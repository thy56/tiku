# 山东专升本 · 四科学习站

一个纯静态的本地学习网站，覆盖语文、英语、高数一、计算机四科。
双击根目录 `index.html` 即可打开，不需要服务器、不需要联网、不需要安装任何依赖。

## 统一规范

**导航层级**：总站 → 科目首页 → 科目内页面，三级。
**导航分两层，全站 21 页统一**：

| 层 | 位置 | 高度 | 作用 |
|:--|:--|:--|:--|
| 全局条（深蓝） | 最顶，`z-index:500` | 38px | 左「专升本」回总站；右侧语文／英语／高数／计基，每个可展开该科全部页面 → **跨科直接跳，不用回总站** |
| 科目条（浅色） | 全局条下方，`z-index:300` | 52px | 当前科目内部导航（练习／知识体系／题库…） |
| 筛选栏 | 科目条下方，`z-index:200` | 自适应 | 搜索与章节筛选（题库、知识类页面才有） |

三层 `top` 依次为 `0 / 38px / 90px`，滚动时逐层吸附不重叠。窄屏（≤820px）自动降到 `0 / 36px / 86px`。

**视觉规范**（四科共用同一套变量）：

| 变量 | 值 | 用途 |
|:--|:--|:--|
| `--blue-700` | `#1f4e79` | 主色、当前页标记 |
| `--blue-500` | `#2e74b5` | 链接、强调 |
| `--ink` | `#243342` | 正文 |
| `--ink-3` | `#6b7c8d` | 次要文字 |
| `--line` | `#e6ecf2` | 分隔线 |
| `--green` | `#3f8f4a` | 答对 |
| `--red` | `#c0504d` | 答错 |
| `--r-sm / --r / --r-lg` | `8 / 10 / 14px` | 圆角三级 |

字体：`Microsoft YaHei → PingFang SC → Hiragino Sans GB → Noto Sans SC`

**页面结构统一**：每页都是 `顶栏导航 → 页头（标题+数量徽章）→ 筛选栏 → 内容区 → 页脚`。

## 交互功能（四科一致）

| 功能 | 说明 |
|:--|:--|
| 作答自动保存 | 打字即存 localStorage，关掉浏览器再开仍在 |
| 选择题即时判分 | 点选项立刻显示绿（对）/ 红（错），并展开解析 |
| 填空先写后对照 | 自己写答案，点「对照答案」才显示参考答案与解析 |
| 自评标记 | 填空/计算题自己判「答对了 / 答错了」 |
| 只看错题 | 一键筛出做错的题 |
| 只看未做 | 筛出还没做的题 |
| 正确率进度条 | 总题 / 已做 / 做对 / 百分比 |
| 筛选记忆 | 选过的章节下次打开还在 |
| 一键重置 | 清空全部作答 |

数据都存在**本机浏览器本地**（localStorage），不上传任何地方。换浏览器或清缓存会清空。

## 维护说明

**改题库数据**：改各科 `data\questions.js`（或 `data\data.js`），页面自动读取，无需改 HTML。

**改科目统计**：改 `assets\subjects.js` 里的 `stats` 与各科 `nums`，总站首页自动更新。

**加新科目**：在 `subjects.js` 的 `subjects` 数组里加一项，`pages` 里列出该科所有页面，总站会自动渲染出卡片和页面索引。

**各科导航**：由各科自己的 `assets\nav.js` + `assets\manifest.js` 生成，互不依赖。

## 打开方式

**电脑**：双击 `index.html`。

**手机**：
1. 把整个「专升本」文件夹拷到手机存储
2. 用文件管理器找到 `index.html`，选择浏览器打开

**注意**：部分手机浏览器对 `file://` 下的多文件引用有限制，若页面空白，改用电脑打开，或用任意静态服务器（如 `python -m http.server`）起服务后访问。

## 页面分页规则（2026-10-28 新增）

**原则：一页看不完的内容，拆成「目录页 + 单页」。** 不再把所有内容堆在一个页面里。

### 机制

所有列表型页面支持 `?ch=<key>` 参数：

- **无参数** → 显示**目录页**（章节卡 / 篇目卡 / 年份卡，一眼看全，点进去看详情）
- **有参数** → 只渲染**该单元**的内容（一章 / 一篇 / 一组 / 一年）
- 参数非法 → 自动回退到目录页，不会白屏

### 各页拆分方式

| 页面 | 目录页显示 | 单页内容 | key 形式 |
|:---|:---|:---|:---|
| 高数一 know.html | 7 章卡片 | 该章知识点 | `?ch=1`..`7` |
| 高数一 examples.html | 7 章卡片 | 该章例题 | `?ch=1`..`7` |
| 高数一 practice.html | 7 章卡片 | 该章题目 | `?ch=1`..`7` |
| 计算机 know/examples/practice | 8 章卡片 | 该章内容 | `?ch=1`..`8` |
| 语文 wen.html | 25 篇（按时代分组） | 该篇全文 | `?ch=01`..`25` |
| 语文 changshi.html | 4 板块卡片 | 该板块条目 | `?ch=A`..`D` |
| 语文 zhenti.html | 4 年份卡片 | 该年真题 | `?ch=2021`..`2024` |
| 英语 grammar.html | 5 章卡片 | 该章语法点 | `?ch=0`..`4` |
| 英语 tenses.html | 5 层卡片 | 该层时态 | `?ch=0`..`4` |
| 英语 vocab.html | 6 类卡片 | 该类词汇 | `?ch=c0`..`c3` / `phrase` / `confus` |
| 英语 roots.html | 56 组卡片 | 该组词根 | `?ch=1`..`56` |

### 导航组件

`assets/chapnav.js`（四科共用）提供：

- 顶部**章节条**：横向列出所有单元，当前高亮，点即跳转
- 底部**上一 / 下一页**：读完直接翻到下一章
- **目录卡片**：`ci-card` 网格，含标题、简介、数量统计

> 语文和英语的 `practice.html` 本来就按组翻页（内置上一组/下一组），本次未改动。
