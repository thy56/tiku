# tools/ —— 构建与数据生成脚本

本目录存放建站期使用的程序代码，**不参与网站运行**，已在
`../.dockerignore` 中排除，不会发布到公网。

## 内容

- 根级：站点数据生成/校验脚本（_data1.py、_gen.js、_lib.js 等）
- `语文/`：题库生成、校验、探针脚本，及资料库索引构建脚本

## 注意

这些脚本读取的**源资料仍保留在原项目目录**：

- `专升本/语文/正式版题库/`（题面JSON、docx 教案）
- `专升本/语文/资料库/`（篇目与常识 JSON）
- `专升本/英语/`（词根素材库.json 等）

如需重新生成站点数据，请从原目录运行或调整脚本内的相对路径。
成品网站直接读取 `../<学科>/data/*.js`，不依赖本目录。
